# جيت

الإصدار **1.2.0** (versionCode 3)

جدول بيور جيم: خمس حصص أجهزة في الأسبوع، ستريك لا ينكسر في يومي الراحة، تسجيل الأوزان، وقياس الخصر والوزن مع صورة أسبوعية. البيانات تبقى على الجهاز.

## التثبيت على أندرويد

1. من [الإصدار 1.2.0](https://github.com/aalbahrii999/jeet/releases/tag/v1.2.0) نزّل `jeet-1.2.0.apk`.
2. افتح الملف على الجوال. التحديث يثبَّت فوق 1.1.0.
3. عند أول فتح، اسمح بالإشعارات.

معرّف التطبيق: `app.jeet`

## داخل التطبيق

- **اليوم:** اللهب، تقدم 5/5، ونقل حصة فائتة إلى الأربعاء أو السبت.
- **التمرين:** الأحد دفع، الاثنين سحب، الثلاثاء أرجل، الخميس علوي، الجمعة سفلي. صور أجهزة النادي، مع الراحة المكتوبة لكل جهاز.
- **جلسة قصيرة:** إحماء وجهازان، وتحسب حضورًا.
- **القياس:** الخصر والوزن، وصورة أسبوعية للجسم.
- **إحصاء:** أعمدة الحضور وPDF فيه الحصص والأوزان والقياس والصور.
- **الإعدادات:** وقت حصة النادي، ووقت تذكير الجمعة.
