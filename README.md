# جيت · كل حصة، خطوة.

الإصدار **2.0.0** — versionCode **5**. معرّف أندرويد `app.jeet`. النشر المستقر مشروط بتطابق مفتاح التوقيع الأصلي؛ لا تُستخدم نسخة debug كتحديث رسمي.

تطبيق عربي لتسجيل التدريب محليًا على الجهاز. لا تتطلب تجربة التدريب حسابًا أو اتصالًا بالإنترنت.

## التجربة الجديدة

- هوية موحدة: شعار متجهي وأيقونة تطبيق، خلفية داكنة وألوان ليمونية دافئة، وخط IBM Plex Sans Arabic بأحجام وتباعد أوضح.
- **اليوم:** الحصة القادمة، أسبوع من الأحد إلى السبت، الأيام المنجزة، الاستمرارية واختصارات القياس.
- **التمرين:** استعراض الحصة قبل البدء، تأكيد كل مجموعة، تسجيل الأرقام والراحة التلقائية، حفظ التقدم واستكماله لاحقًا. تُحفظ المجموعات المؤكدة فقط عند إنهاء حصة غير مكتملة.
- **خطتي:** اختيار أيام التدريب، إضافة الجداول وتعديلها ونسخها وحذفها وإعادة ترتيبها. إضافة تمارين خاصة، وتعديل المجموعات والتكرارات والراحة داخل كل جدول.
- **المكتبة:** تمارين قوة أو كارديو، وأدوات ومجموعات عضلية وملاحظات أداء. تعديل اسم تمرين لا يغير أسماء السجلات السابقة.
- **تقدمي:** الحضور والقياسات والأوزان، فترات زمنية، مقارنة صور، وتقرير PDF مع خيار إدراج الصور. تصدير التقرير لا يستنتج أداء لم يُسجل.
- **المزيد:** التذكيرات، حفظ واستيراد نسخ JSON من منتقي ملفات أندرويد، مراجعة النسخة قبل الاستبدال، وحماية البيانات التي تعذر فتحها.

الحصص تتبع ترتيب الحضور عبر الأسابيع. تعديل الجداول لا يغير الحصة الجارية أو الحصص المسجلة. يبدأ هدف الأسبوع الجديد من أيامك المختارة، وتحتفظ الأسابيع السابقة بأهدافها المسجلة.

## الراحة في جيبك

ابدأ الراحة يدويًا أو تلقائيًا بتأكيد مجموعة. يظهر العداد فوق التنقل، ويمكن إضافة ٣٠ ثانية أو إلغاؤه. تستخدم نسخة أندرويد منبهًا أصليًا وثلاث نبضات اهتزاز عند الانتهاء، مستقلًا عن تشغيل WebView.

إذا ظهر «اسمح بتنبيه الراحة»، اسمح بالمنبهات الدقيقة من الإعدادات. دون السماح قد يؤخر أندرويد التنبيه البديل. يتبع الاهتزاز إعدادات الجهاز وعدم الإزعاج. يظهر رمز المنبه وموعد انتهاء الراحة ضمن المنبه القادم أثناء عمل المنبه الدقيق. اختبار عدة جولات مع الشاشة المقفلة مطلوب قبل الإصدار.

## البيانات والترحيل

تُقرأ بيانات 1.3 من المفتاح نفسه `jeet.v1`، وتُرحل إلى مخطط الإصدار 2 مع الاحتفاظ بالحصص والقياسات والصور. لا تُكتب الحالة الفارغة فوق بيانات تعذر تحليلها. تظهر رسالة استرداد وتتاح نسخة النص الأصلي من الإعدادات. يُرفض ملف الاستيراد غير الصالح قبل تغيير الحالة.

الصور محفوظة في التخزين المحلي؛ إذا امتلأ، يُرفض التغيير مع توضيح فشل الحفظ. يمكنك تصدير نسخة ثم حذف صور لا تحتاجها. لا توجد مزامنة سحابية تلقائية.

## البناء والفحص

يتطلب Node.js 22.13 أو أحدث، وJDK 17، وAndroid SDK 35.

```sh
npm ci
npm run test:jeet
npm run typecheck
npm run build:apk
npx playwright install chromium
node scripts/browser-jeet-smoke.mjs
cd android
bash gradlew assembleDebug
```

تعيد مهمة Gradle `preBuild` توليد ملفات واجهة APK تلقائيًا. مسار النسخة التجريبية `android/app/build/outputs/apk/debug/app-debug.apk`. إصدار التحديث الرسمي يحتاج مفتاح التوقيع نفسه المستخدم في النسخة المثبتة؛ لا تغيّر هوية التطبيق أو تمسح بياناته لتجاوز اختلاف التوقيع.

يفحص `.github/workflows/verify-app.yml` المنطق والأنواع وبناء الواجهة، ثم يجرب دورة استخدام على Chromium بأحجام 320 و390 و768 بكسل ويُرفق الصور وAPK التجريبي عند نجاح البناء. لا يحل هذا محل تجربة الاهتزاز والكاميرا ومنتقي الملفات على جهاز أندرويد فعلي.

لإصدار تحديث مستقر، يستخدم مسار `Release Jeet` مفتاح التوقيع الأصلي من أسرار المستودع. يقارن توقيع APK الناتج وهويته بالنسخة 1.3.0، ويوقف النشر عند الاختلاف. بعد الدمج إلى `main` ونجاح الفحوصات ينشر `v2.0.0` وملف `jeet-2.0.0.apk` في إصدارات المستودع. إعداد المفتاح: [توقيع التحديث](docs/release-signing.ar.md).

التفاصيل: [مراجعة الإصدار الثاني](docs/jeet-2-validation.md)، و[فحص عداد الراحة](docs/rest-timer-validation.md).
