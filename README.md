# جيت

الإصدار **1.3.0** (versionCode 4)

جدول بيور جيم: خمس حصص أجهزة في الأسبوع، والحصص تتبع ترتيب الحضور. البيانات تبقى على الجهاز.

## التثبيت على أندرويد

1. من [الإصدار 1.3.0](https://github.com/aalbahrii999/jeet/releases/tag/v1.3.0) نزّل `jeet-1.3.0.apk`.
2. افتح الملف على الجوال. التحديث يثبَّت فوق 1.2.0.
3. اسمح بالإشعارات. والكاميرا تُطلب عند أول صورة.

معرّف التطبيق: `app.jeet`

## داخل التطبيق

- **اليوم:** اللهب، تقدم 5/5، وحذف حضور اليوم إذا سُجّل بالغلط.
- **الترتيب:** دفع، سحب، أرجل، علوي، سفلي. إذا فاتك الأحد، تمارين الأحد تنتقل لليوم الذي تحضر فيه.
- **التمرين:** صور أجهزة النادي، مع الراحة المكتوبة لكل جهاز.
- **جلسة قصيرة:** إحماء وجهازان، وتحسب حضورًا.
- **القياس:** الخصر والوزن، وصورة أسبوعية للجسم من الكاميرا أو المعرض.
- **إحصاء:** أعمدة الحضور وPDF فيه الحصص والأوزان والقياس والصور.
- **الإعدادات:** وقت حصة النادي، ووقت تذكير الجمعة.

## عداد الراحة

- ابدأ الراحة من صفحة الجهاز. يظهر العداد فوق شريط التنقل ويستمر عند تغيير الصفحة.
- يمكنك إضافة ٣٠ ثانية أو إلغاء الراحة. انتهاء الجلسة يلغي عدادها.
- نسخة أندرويد تنبّه بثلاث نبضات اهتزاز قصيرة عند نهاية الراحة، حتى مع قفل الشاشة. يتبع الاهتزاز إعدادات الجهاز ووضع عدم الإزعاج.
- إذا ظهر «اسمح بتنبيه الراحة»، افتحه واسمح بالتنبيهات الدقيقة لتقليل تأخر التنبيه عند قفل الجوال. دون هذا السماح يستخدم التطبيق تنبيهًا قد يؤخره النظام.
- أثناء الراحة قد يعرض أندرويد رمز المنبه وموعد انتهاء الراحة ضمن المنبه القادم؛ الضغط عليه يفتح العداد.
- في المتصفح يستمر حساب الموعد الصحيح، لكن الاهتزاز في الخلفية يعتمد على دعم المتصفح؛ تنبيه الجيب يحتاج نسخة أندرويد المحدثة.

## بناء التعديل

يتطلب Node.js 22.13 أو أحدث واعتماديات npm، وJDK 17 وAndroid SDK 35 لبناء أندرويد.

```sh
npm ci
npm run test:rest
npm run build:apk
cd android
./gradlew assembleDebug
```

تُعيد مهمة Gradle `preBuild` توليد ملفات الواجهة تلقائيًا؛ تعديل المصدر وحده لا يغير ملفات APK المنشورة سابقًا. ملاحظات التحقق اليدوي في `docs/rest-timer-validation.md`.
