# جيت 2.0.0

- واجهات وشعار وألوان وخط عربي جديدة، وتنقل أوضح بين التدريب والخطة والتقدم.
- إضافة التمارين والجداول وتعديلها ونسخها وترتيبها، مع الحفاظ على أسماء وتفاصيل الحصص السابقة.
- عداد راحة مستمر، يبدأ تلقائيًا بعد تأكيد المجموعة، مع تمديد الوقت واهتزاز عند النهاية على أندرويد.
- تحسين حفظ الأوزان والتكرارات، واستكمال الحصص، وتسلسل التدريب بين الأسابيع.
- نسخ احتياطية JSON مع معاينة الاستيراد، وتقارير PDF ومقارنة الصور.
- ترحيل بيانات النسخ السابقة من التخزين نفسه دون مسح الحصص والقياسات والصور.

نزّل `jeet-2.0.0.apk` وثبّته فوق النسخة الحالية باختيار «تحديث». لا تحذف التطبيق قبل التثبيت؛ الحذف يمسح بياناته المحلية. معرّف التطبيق `app.jeet`، ورقم البناء 5. يفحص النشر تطابق شهادة التوقيع مع النسخة المنشورة 1.3.0.

للتنبيه أثناء قفل الشاشة، اسمح بتنبيهات الراحة الدقيقة من داخل التطبيق. يتبع الاهتزاز إعدادات الهاتف وعدم الإزعاج.
