# مراجعة تطوير جيت 2.0

## ما تغير

- أُعيد تصميم شاشات اليوم والتدريب والخطة والتقدم والإعدادات، مع شعار موحد وأيقونة أندرويد وSVG وPNG.
- أصبحت الجداول والتمارين بيانات قابلة للتعديل، مع هوية مستقرة ولقطات محفوظة داخل سجل كل تمرين. لا تعيد تعديلات المكتبة تسمية الحصص السابقة ولا تغير مسودة حصة بدأت بالفعل.
- تبدأ الأسابيع الأحد وتنتهي السبت؛ تعويض السبت ينتمي للأسبوع نفسه. تستمر دورة الجداول حسب آخر حصة دون إعادة ضبطها عند تغير الأسبوع.
- يشترط تسجيل مجموعة وتأكيدها قبل إدراجها ضمن الحصة. تُترك التكرارات فارغة في المسودة الجديدة؛ الوزن السابق مجرد اقتراح قابل للتغيير.
- ينتقل الاستيراد من تحويل نوع TypeScript إلى فحص بنية فعلية. تحفظ العمليات الحالة الجديدة بعد نجاح الكتابة، ويظل الأصل قابلًا للاسترداد إذا فشلت القراءة.
- يشمل منتقي ملفات أندرويد تصدير واستيراد JSON. تعرض الواجهة ملخص النسخة قبل استبدال البيانات. إخفاق العملية لا يحذف البيانات الحالية.
- أصبحت صور الجسم اختيارية في PDF، ويلتقط التصدير صفحات محدودة الحجم بدل لوحة واحدة بطول السجل كله.

## التحقق المحلي

- اجتازت ٢٤ حالة اختبار، إضافة إلى مجموعتي الاختبار: ٢٦ نتيجة ناجحة. تشمل الجداول المخصصة وإعادة ترتيبها ونسخها وحذفها، وحماية آخر جدول، وترحيل النسخ، والتحقق من محتوياتها، وفشل القراءة والكتابة، وتعويض السبت واستمرار الترتيب، وأوزان الرجوع، وعداد الراحة.
- فُحصت صياغة جميع ملفات TS/TSX الخاصة بالتطبيق باستخدام محلل Babel، وصياغة سكربتات Node وملفات XML وJSON.
- حُجب تشغيل Chromium محليًا بسياسة البيئة؛ لم يُعتبر نجاح فحص الصياغة بديلًا لفحص المتصفح. أضيف فحص مستقل إلى GitHub Actions؛ راجع حالة التشغيل وأدلة الصور قبل الدمج.

## فحص المتصفح الآلي

`scripts/browser-jeet-smoke.mjs` يستخدم ملف واجهة APK الفعلي الناتج من Vite. ينشئ تمرينًا وجدولًا، ويسجل مجموعة، ويشغل الراحة ويمددها، وينهي حصة جزئية، ويسجل قياسًا، ويصدر نسخة بيانات، ويرفض ملفًا غير صالح، ويستورد نسخة صالحة ثم يتحقق من بقائها بعد إعادة التحميل. يختبر عرض 320 و390 و768 بكسل ويرفض الاستثناءات في المتصفح. تحفظ أدلته في `artifacts/jeet-browser`.

## قبل الإصدار الرسمي

1. تحقق من نجاح فحص الأنواع وبناء Vite وGradle، ومراجعة الصور المرفقة في تشغيل GitHub Actions الخاص بآخر commit.
2. اختبر التحديث فوق نسخة 1.3 بملف بيانات واقعي، مع نسخة احتياطية خارج التطبيق. استخدم مفتاح التوقيع الأصلي عند بناء التحديث؛ APK الموقّع بمفتاح debug جديد لا يضمن تحديث النسخة القديمة.
3. جرّب الراحة لعدة جولات والشاشة مقفلة، مع السماح بالتنبيه الدقيق ورفضه، ووفق إعدادات الاهتزاز وعدم الإزعاج.
4. اختبر الكاميرا والمعرض ومنتقي ملفات JSON على أندرويد 8 و12 و15 أو الأجهزة المتاحة. ألغ اختيار الملف، وجرّب ملفًا معطوبًا وكبيرًا ومساحة تخزين ممتلئة.
5. جرّب تعديل جدول أثناء وجود حصة غير مكتملة، وحذف جدول مع وجود سجلات سابقة، وتغيير أيام الأسبوع. يجب أن تبقى المسودة والسجلات سليمة.
6. جرّب قارئ الشاشة وتكبير الخط والتنقل بلوحة المفاتيح. يجب أن تُعلن أخطاء الحفظ ونهاية الراحة، وأن يبقى التركيز داخل نوافذ التحرير.
7. راجع PDF متعدد الصفحات، بأكثر من حصة وصور مفعلة ومعطلة، وتحقق من أن ترحيل القياسات والوزن لا ينتج عنه ادعاء تقدم غير مسجل.

لم يُنشر إصدار رسمي من هذا التعديل أثناء التحرير. يُحدّث طلب المراجعة بنتائج البناء الفعلية عند توفرها.
